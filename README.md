# 🎬 AnimeFlix Lite

A lightweight, free anime discovery website built as a static prototype.

## ✨ Features
- Browse top 50 anime from MyAnimeList
- Search by title
- Filter by genre
- Save favorites to watchlist (saved in your browser)
- Click any card to see synopsis
- "Watch" button opens Google search for legal streaming options

## 🛠️ Built With
- HTML5
- CSS3 (Grid, Flexbox, animations)
- Vanilla JavaScript
- [Jikan API](https://jikan.moe) (unofficial MyAnimeList API)
- localStorage for watchlist persistence

## 📦 Deploy on GitHub Pages
1. Fork or clone this repo
2. Push to GitHub
3. Go to Settings → Pages → set branch to `main`
4. Your site will be live at `yourusername.github.io/repo-name`
